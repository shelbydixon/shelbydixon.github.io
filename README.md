# Shelby Dixon Portfolio

Professional portfolio for Shelby Dixon.

**Live site:** <https://shelbydixon.github.io>

## Structure

- `index.html` — professional identity and selected-work overview
- `projects.html` — detailed selected project case studies
- `experience.html` — employment, research, and field experience
- `resume.html` — résumé summary and PDF links
- `contact.html` — public contact page
- `assets/documents/Shelby_Dixon_Resume.pdf` — current one-page résumé
- `styles.css` — shared visual design

## Design direction

This version intentionally uses no photographs, stock graphics, gradients,
neon effects, or generic technology icon walls. The site relies on clear
writing, editorial typography, and evidence.

## Publishing

GitHub Pages should be configured to deploy from:

- Branch: `main`
- Folder: `/(root)`
